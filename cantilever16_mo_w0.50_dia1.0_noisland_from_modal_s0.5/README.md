# cantilever16_mo_w0.50_dia1.0_noisland_from_modal_s0.5 (금속 외팔보, 설계)

외팔보 16x5x5 (400칸), **칸 5 mm, 격자 80 x 25 x 25 mm.** 좌표와 반지름은 실제 mm. 2026-10-02.
다목적 w0.50 설계, 셀 의존 밀도 하한 (10 mm 칸 기준 막대 1.0 mm, 이 크기에서 **최소 0.50 mm**), 섬 금지 수리 (세워서 출력 기준 섬 0).
10 mm 칸 설계 (`design_cantilever16_mo_w0.50_dia1.0_noisland_from_modal.npz`) 를 0.5 배로 줄인 것. 셀·방향·밀도 배치는 같다.

- **출력 방향.** 세워서. x 가 적층 방향, x = 0 (고정단, 플랜지 쪽) 이 바닥판. 격자 안에 서포트 없음.
- **재료.** IN718. 해석 물성은 E 165 GPa, ν 0.30, ρ 8,220 kg/m³ (ANSYS AM 라이브러리) 로 맞춘다 [확인].
- **무게.** 칸마다 상자로 자른 기준 격자 7,500 mm³ (IN718 약 61.7 g). 막대를 자르지 않으면 더 무거움.
- **균질화 예측 (칸마다 자른 형상, 맨몸 외팔보, x = 0 고정).** f1 IN718 약 2,907 Hz. 같은 무게 균일 (5449) 대비 1.563 배, 강성 1.092 배.
- **병합 규칙.** 칸 경계 위 막대는 RMS 반지름 하나. 이웃 칸에 짝이 없는 막대는 원래 반지름 그대로 (0 을 넣지 않음).

파일. nodes.csv (`id,x,y,z`), struts.csv (`id,n1,n2,radius_mm,length_mm,shared_by`), blocks.csv (칸별 셀·방향·밀도·반지름, 원점 mm),
cell_graphs.csv (셀 안 막대, 좌표 0~1 = 칸 5 mm 로 나눈 값).

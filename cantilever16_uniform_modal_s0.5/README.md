# cantilever16_uniform_modal_s0.5 (금속 외팔보, 균일)

외팔보 16x5x5 (400칸), **칸 5 mm, 격자 80 x 25 x 25 mm.** 좌표와 반지름은 실제 mm. 2026-10-02.
400칸 전부 셀 5449 방향 p1, 공칭 밀도 0.1913 (예산 15%), **막대 지름 0.756 mm (반지름 0.37798) 하나.**
설계 벌 `cantilever16_mo_w0.50_dia1.0_noisland_from_modal_s0.5` 의 짝. 세워서 출력할 때 섬 0, 수평 막대 경간 전부 2.5 mm.

- **무게 맞추기.** 이 반지름은 칸마다 상자로 자른 기준 무게가 설계와 같은 값이다. 자르지 않은 형상에서는 설계가 더 무거우므로,
  PA 때와 같이 설계 STEP 부피에 맞춰 이 막대를 굵혀서 쓴다.
- **균질화 예측.** f1 IN718 약 1,860 Hz (맨몸 외팔보, x = 0 고정, 칸마다 자른 형상).
- 출력 방향, 재료, 파일 형식은 설계 벌 README 와 같다.
